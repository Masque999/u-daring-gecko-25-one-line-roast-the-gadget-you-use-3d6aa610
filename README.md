# One-Line Roast: The Gadget You Use Every Day

One line, at most 200 characters, roasting a gadget used every day.

Entry: `My smart speaker hears me perfectly when I am talking to someone else, and goes deaf the moment I actually ask it something.`

Run: `node main.ts` (writes the line to `/output/entry.txt`).
